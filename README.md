# חמישי משפחתי

אפליקציה קטנה לערב המשפחתי של יום חמישי: בנק רעיונות (בבית / בחוץ), הצבעה של כל בני הבית, סימון "עשינו" והיסטוריה עם דירוגים.

## איך זה בנוי

- **המסכים** הם האתר הזה, שמוגש מ-GitHub Pages ואפשר להתקין אותו על מסך הבית (PWA).
- **הנתונים** נשמרים ב-Google Sheet של המשפחה. האתר מדבר עם הגיליון דרך Google Apps Script.
- **קוד משפחתי** שנבחר בתוך האפליקציה מגן על הנתונים. הוא נשמר בגיליון ולא במאגר הזה.

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל המסכים, העיצוב והלוגיקה |
| `manifest.webmanifest`, `sw.js`, `icons/` | התקנה על מסך הבית ופתיחה בלי רשת |
| `apps-script/Code.gs` | צד הגיליון. העותק כאן הוא המקור, ומה שרץ בפועל הוא מה שפרוס בעורך של Apps Script |

## עדכונים

- שינוי במסכים: דחיפה לענף `main`, והאתר מתעדכן תוך דקה או שתיים.
- שינוי ב-`apps-script/Code.gs`: צריך גם להדביק אותו בעורך של Apps Script ולפרוס גרסה חדשה (פריסה > ניהול פריסות > עריכה > גרסה חדשה).

## תצוגת הדגמה

הוספת `?demo=1` לכתובת פותחת את האפליקציה עם נתונים לדוגמה, בלי לגעת בגיליון.
