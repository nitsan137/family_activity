# חמישי משפחתי

אפליקציה קטנה לערב המשפחתי של יום חמישי: בנק רעיונות (בבית / בחוץ), הצבעה של כל בני הבית, סימון "עשינו" והיסטוריה עם דירוגים. אפשר להתקין אותה על מסך הבית (PWA).

## איך זה בנוי

- **כל הקוד כאן.** המסכים וכל ההיגיון של האפליקציה נמצאים ב-`index.html` ומוגשים מ-GitHub Pages.
- **הנתונים בגיליון Google של המשפחה.** הגיליון הוא הדאטהבייס, ואפשר לפתוח ולערוך אותו גם ביד.
- **"דלת" קבועה ב-Apps Script.** דף אינטרנט לא יכול לכתוב לגיליון בעצמו, אז בגיליון יושב קוד קצר (`apps-script/Code.gs`) שרק קורא וכותב שורות ובודק את הקוד המשפחתי. הוא לא מכיר את האפליקציה, ולכן לא משתנה כשהיא משתנה.
- **קוד משפחתי** שנבחר בתוך האפליקציה מגן על הנתונים. הוא נשמר בגיליון ולא במאגר.

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל המסכים, העיצוב וההיגיון |
| `data/patches.json` | שינויי נתונים שמוחלים על הגיליון, ראו `data/README.md` |
| `manifest.webmanifest`, `sw.js`, `icons/` | התקנה על מסך הבית ופתיחה בלי רשת |
| `apps-script/Code.gs` | הדלת של הגיליון. מדביקים אותה פעם אחת בעורך של Apps Script |

## עדכונים

- **מסכים והיגיון:** דחיפה לענף `main` וגם לענף `gh-pages`, שממנו האתר מוגש. האתר מתעדכן תוך דקה או שתיים.
- **נתונים** (למשל להוסיף רעיונות): מוסיפים שינוי ל-`data/patches.json` ודוחפים. הוא מוחל על הגיליון בפתיחה הבאה של האפליקציה.
- **לשונית או עמודה חדשה בגיליון:** מוסיפים אותה ל-`SCHEMA` ב-`index.html`, והיא נוצרת לבד.

## תצוגת הדגמה

הוספת `?demo=1` לכתובת פותחת את האפליקציה עם נתונים לדוגמה, בלי לגעת בגיליון.
