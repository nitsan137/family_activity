# שינויי נתונים דרך המאגר

`patches.json` הוא רשימה של שינויים בנתונים. האפליקציה קוראת אותו בכל פתיחה, ומחילה על הגיליון כל שינוי שעוד לא הוחל. כל שינוי רץ פעם אחת בלבד, לפי ה-`id` שלו, ולכן מוסיפים שינוי חדש בסוף הרשימה עם `id` חדש ולא עורכים שינוי ישן.

מה אפשר לכתוב ב-`changes`:

| `do` | מה זה עושה | שדות |
|---|---|---|
| `addIdea` | מוסיף רעיון, אם אין כבר רעיון באותו שם | `title`, `pic`, `place` (`home` או `out`), `note` |
| `editIdea` | משנה רעיון קיים לפי השם | `title`, `set` עם `title` / `pic` / `place` / `note` |
| `removeIdea` | מסיר רעיון מהרשימה (ההיסטוריה נשארת) | `title` |
| `restoreIdea` | מחזיר רעיון שהוסר | `title` |
| `editMember` | משנה בן משפחה לפי השם | `name`, `set` עם `name` / `emoji` / `active` |
| `setHearts` | כמה לבבות לכל אחד בשבוע | `value` (1 עד 5) |
| `removeEvening` | מוחק ערב מההיסטוריה | `date`, ואפשר גם `titles` |
